# How each of the factors that meditation affects, affects chess:
## working memory
- When calculating "branches" of moves, being able to hold in memory the different branches and their consequences in memory leads to better ability to judge which one to choose if any.
- When calculating, being able to hold in memory the position after calculated moves, and which moves happened from current position to there and possible branches.
- When realizing a threat, being able to hold it in memory while thinking of other things.
